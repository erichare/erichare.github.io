Built through [JEStats](https://jestats.io), the Astra DB Plugin connects coding agents to a live database so they can work from its actual structure.

## What it helps with

- Explore databases, collection schemas, and documents.
- Run vector and hybrid searches.
- Build application code using Data API examples in five languages.
- Make data changes with confirmation for destructive operations and an optional read-only mode.

The plugin includes an MCP server, coding-agent skills, and interactive data views in compatible hosts. Native plugin paths are available for Codex and Claude Code.

This is an unofficial, community-maintained integration by JEStats. It is not an official DataStax or IBM product.
