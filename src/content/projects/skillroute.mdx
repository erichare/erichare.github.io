SkillRoute is an open-source project from [JEStats](https://jestats.io) that helps coding agents choose from a growing library of skills.

## What it helps with

- Index complete `SKILL.md` bundles, including headings and relationships.
- Return ranked matches with confidence and source evidence.
- Ask for clarification when a route is uncertain.
- Explore the library visually through Skill Atlas.

The default catalog uses local SQLite. A CLI, MCP server, and community plugins for Codex and Claude Code bring routing into existing workflows. Optional retrieval backends support larger libraries, and route traces make decisions inspectable.
