Codebase Mentor is an open-source project from [JEStats](https://jestats.io) for understanding unfamiliar repositories and planning changes with inspectable evidence.

## What it helps with

- Trace architecture and execution paths through current source.
- Find relevant files, symbols, examples, and tests for a change.
- Check assumptions and documentation against the code.
- Draft an onboarding guide your team can review and maintain.

It works as native Codex and Claude Code plugins, IBM Bob skills, or open-format skills for other agents. The core skills need no separate runtime, database, or API key. Answers cite the source the agent reads and identify gaps in the available evidence.
